# 도시 능력자 모드 (bbc)

Fabric 1.21.1. 코블몬 없이 단독으로 돈다. 기획은 claude.ai의 "도시 능력자 서버 — 기획안" 문서.

## 빌드
`city-ability` 폴더에서 `gradlew.bat build` → `build/libs/bbc-city-ability-<버전>.jar`
(서버와 클라이언트 둘 다에 넣는다. 평타·가드·대시 입력이 클라이언트 쪽에 있다.)

## 조작 (전투 모드 중)
평타 한 사슬은 5타. 땅·공중을 섞어서 센다. 좌클릭은 누르고 있어도 된다 (0.35초마다 한 대).
평타를 치는 동안은 바닐라 점프가 막힌다. 스페이스는 평타 갈래를 고르는 데만 쓰인다.

| 입력 | 동작 |
| --- | --- |
| 좌클릭 5번 | 4타 + **넉백** (날려보냄. 가드는 못 깸). 날아가는 상대는 Q로 쫓아가 다시 잡을 수 있음 |
| 좌클릭 4번 → 스페이스 누른 채 1번 | **업 플링** (상대만 높이 띄움). 떨어지는 상대를 점프해 공중 평타로 이음 |
| 좌클릭 1~3번 → 스페이스 누른 채 평타 (2~4타째) → 스페이스 떼고 5타째 | 같이 떠서 공중 평타 → **다운 슬램** (꽂히고 튕김, 튕기는 동안 기술이 들어감) |
| 공중에서 스페이스 누른 채 5타째 | **드롭킥** (두 발로 차서 상대를 수평으로 멀리 날림, 대시로 쫓아가 이음). 스페이스를 떼고 5타째면 다운 슬램 |
| F 누르고 있기 | 가드 (앞쪽 피해 80% 감소, 게이지 소모). 누르는 순간 3틱은 패링 (헛치면 1.5초, 성공해도 2.5초 동안 다시 패링 못 함. 패링당한 쪽은 20틱 경직. 패링 불가 공격은 보스 패턴 등에 따로 지정) |
| Q (방향키와 같이) | 대시 5칸 (짧은 무적, 스태미나 15). 평타 후딜 중이면 대시 캔슬 (25) |
| 날리거나 띄운 상대를 보고 Q | 추격 대시: 그 상대 앞까지 날아가 붙음 (공중이면 바로 공중 평타) |
| 맞는 중에 Q | 회피기 (콤보에서 빠져나옴, 30초 재사용) |
| 숫자 1~5 | 직업 기술 (경직·다운 중엔 안 나감). 평타 사이 아무 때나 끼워 넣을 수 있음. 전투 모드 동안 핫바 1~5 전환은 막힘 |

평타 판정은 내 앞에 둔 구(반지름 1.6칸)라서 옆으로 살짝 빗겨 있어도 맞는다.

**지상 콤보 (ABA처럼 평타 4 → 연계기 → 평타 4 …)**
- 기술을 쓰면 평타 사슬이 처음부터 다시 시작한다 (다시 4타를 치고 5타째가 마무리)
- 땅에서 기술로 맞힌 상대는 경직이 최소 16틱이고 내 앞 1.9칸에 붙잡혀서, 기술 뒤 평타가 바로 이어진다
- 수련생 예: 평타 4 → 5(어깨치기) → 평타 4 → 1(돌진 베기) → 평타 4 → 3(밀쳐내기)로 마무리

## 스위치 (`combat/Weapon`)
- 핫바 1번 칸 = 클래스(직업 평타 + 직업 기술 1~5), 2번 칸 = 무기 A, 3번 칸 = 무기 B
- **E** = 스위치 (클래스 → 무기 A → 무기 B, 무기 없는 칸은 건너뜀). 전환 5틱. 전투 모드 동안 E 인벤토리는 막힘 (` 로 끄고 열기)
- 무기 칸에선 평타가 무기 평타로, 숫자 1·2 = 무기 기술

| 무기 | 판별 | 평타 | 기술 1 | 기술 2 |
| --- | --- | --- | --- | --- |
| 검 | 모든 검 | 5타, 피해 ×1.2 | 올려베기 (띄우기) | 질풍베기 (돌진 연계기) |
| 창 | 삼지창 | 4타, 사거리 +1칸 | 꿰뚫기 (긴 찌르기) | 연속 찌르기 (꾹) |
| 대검 | 모든 도끼 | 느린 3타, 피해 ×2 | 가르기 (가드 깨기 + 다운) | 휠윈드 (꾹) |

- **꾹 누르는 기술** (`combat/Channel`): 누르고 있는 동안 스태미나를 쓰며 계속 공격, 떼면 끝
  - 휠윈드: 4틱마다 주위 전부 벰, 최대 3초, 떼면 마지막 한 바퀴로 밀어냄 / 연속 찌르기: 4틱마다 앞으로 찌름, 최대 2.5초
  - 제한: 같은 상대는 6~7번까지만 맞고 마지막엔 밀려남(무한 가두기 방지), 쓰는 동안 느려짐·평타 불가, 공중 시작 불가,
    맞으면 끊김, 재사용은 끝난 뒤부터(기본 + 쓴 시간만큼 더)
- **스위치 캔슬**: 평타·기술 후딜 중에 E → 후딜 취소. 콤보당 2번, 스태미나 15. 클래스 기술 → 무기 기술 → 클래스 기술로 긴 콤보
- 무기 기술 재사용은 직업 기술과 따로 돈다. 몬스터는 손에 든 무기로 평타가 바뀐다 (숙련 연습 상대는 검)

## 각성 (`combat/Awaken`)
- 게이지(화면 위 빨간 막대): 때릴 때 피해×2, 맞을 때 피해×3.2만큼 참 (맞는 쪽이 더 빨리 → 역전 수단)
- 100%에서 **G** → 45초 각성. 체력을 가득 채움(보스는 15%만), 주위 4칸을 밀어내고 1초 무적. 콤보 맞는 중엔 못 함 (회피기가 그 역할)
- 각성 중: 평타 피해 ×1.25, 금빛 오라. 직업별 강화·기술 교체는 직업 쪽 `onAwaken`
- 각성 중 **G** = 각성기 (각성 한 번에 1번, 쓰면 각성 10초 감소). 직업 각성기가 없으면 공통 ‘난무’:
  0.1초마다 8연타 → 마지막 일격은 **패링 불가** 넉백
- 보스 AI도 게이지가 차면 각성하고, 상대가 경직일 때 각성기로 마무리한다

## 몬스터 전투 AI (`combat/MobAI`)
태그가 붙은 몹은 플레이어와 같은 전투 엔진(평타 5타·가드·패링·대시·회피기)을 쓴다. 바닐라 근접 공격은 꺼진다.

| 단계 | 태그 | 하는 것 | 반응 |
| --- | --- | --- | --- |
| 하급 | `bbc_ai_grunt` | 평타 2~5타, 가끔 늦게 가드 | 0.5초 |
| 숙련 | `bbc_ai_skilled` | 평타 5타·업 플링·뜨기→다운 슬램, 가드·패링, 대시로 파고들기, 가드 깨기(빨간 빛 예고), 콤보 중 회피기 | 0.35초 |
| 보스 | `bbc_ai_boss` | 숙련 전부 + 지상 연계(평타 4 → 어깨치기 → 평타 4 → 넉백), 넉백 → 추격 대시 → 공중 콤보 | 0.2초 |

- 시험: `/bbc admin opponent grunt|skilled|boss` (내 앞 5칸에 연습 상대 좀비)
- 아무 몹에나 붙이기: `/tag @e[type=zombie,limit=1,sort=nearest] add bbc_ai_skilled`
- 콤보 뒤엔 1~2초 쉬어서 반격 기회가 있고, 패링·가드는 확률이라 매번 막지는 않는다
- 사람 모양 몹은 평타·가드·슬램 자세를 간단히 잡는다 (플레이어 모션만큼 부드럽진 않음)

## 평타 규칙 (ABA 위키 용어집 + M1 가이드 영상)
- **공중 막타**: 내가 공중이면 (띄운 콤보든 그냥 점프든) 5타째가 공중 막타. 스페이스 **뗌 = 다운 슬램**, **누름 = 에어킥(드롭킥)**
- **땅 슬램·땅 에어킥 테크**: 평타 4타 → 0.5~1초 기다림 → 점프(톡 = 슬램 / 꾹 = 에어킥) → 막타. 4타째는 경직 +8, 사슬 유지 1.2초라 기다려도 이어짐
- **다운 슬램**: 상대가 먼저 꽂혀 1초(20틱) 경직. 슬램한 나는 살짝 떴다 늦게 착지하고, **땅에 닿을 때까지 평타·기술·대시 전부 불가**. 평타는 24틱 막힘 → 평타만으로는 못 잇고 착지 직후 기술(익스텐더)로 이음. 꽂힌 상대에게 기술 = 다시 띄움
- **대시 평타**: 대시 중·직후 8틱 안의 평타(막타 포함)는 판정이 1칸 더 멀리 닿음
- **가드 브레이크**: 1초(20틱) 경직
- (평타 딜레이: 사슬이 1.2초 유지되므로 일부러 늦게 쳐서 상대가 가드를 풀 때 맞히는 것도 됨)

## 띄우기 정렬 (ABA 레이카게 Lariat 연계)
- 크게 띄운 공격(평타 5타+점프 올려치기, 2~4타+점프 뛰어 띄우기, 튕김 띄우기)이 맞으면 12틱 동안 상대의 **가로 위치가 내 앞 1.8칸에 묶임** (높이는 그대로 날아감)
- 이 사이에 넉백 기술을 맞히면 가로 넉백이 묶임에 덮여 상대가 내 앞에 떨어짐 → 원래 연계가 안 되는 넉백 기술로 콤보를 이음. 돌진기로 움직이면 상대도 같이 끌려옴
- 묶인 동안 점프하면 상대 높이까지 따라 올라가게 밀어 줌 (공중 콤보 진입). 내리찍기에 맞으면 풀림

## 전투 중 (in combat)
- 플레이어끼리, 또는 플레이어와 적대 몹·전투 AI 몹이 서로 때리거나 맞으면 15초 동안 **전투 중** (때릴 때마다 갱신, 허수아비 제외). 화면 위 가운데에 붉은 '전투 중 n초' 표시
- 전투 중엔 전투 모드로 켤 수는 있지만 **끌 수는 없음**
- 전투 중에 접속을 끊으면 **도주**: 그 자리에서 쓰러지고(일반 죽음), 이번 파워 존재치 진행의 15% 를 잃고, 다시 들어오면 10분 동안 **부상**(최대 체력 −15%)

## 성장 (3단계) — K 또는 /bbc grow
레벨 없음. **존재치 + 파워(1~50) + 행동 스탯 + 재능 카드 + 특성 + 스킬 숙련 + 종족**.
- **존재치**: 몬스터 처치(최대 체력의 절반, 동물은 15%, 플레이어 20, 보스 AI ×6), 새 바이옴 처음 들어가기 15
- **파워 (1~50)**: 투자 한도 파워 1~19 = 15점, 20부터 = 3점 (총 375점, 스탯 8개 합 800 중 일부만 → 빌드가 갈림). 한도를 다 확정하고 존재치가 문턱 60×(p−1)^2.3 (파워 2=60, 5=1450, 10=9800, 20=52000, 50=470000)을 넘으면 파워업
- **행동 스탯** (최대 100): 행동하면 경험치 → 다 차면 '확정 대기' 1점(최대 9) → 수련 도구 우클릭으로 확정 (필요 경험치 = 40×(1+스탯/12)^1.5: 0점 40 → 30점 248 → 60점 547 → 99점 1156, 갈수록 크게 느려짐. 인간 +10%)

| 스탯 | 쌓는 행동 | 확정 도구 (조합) | 효과 |
| --- | --- | --- | --- |
| 힘 | 근접 평타(맨손 3·무기 1), 나무·광석 캐기 2 | 아령 (철 7) | 맨손 평타 피해 +0.4%/점, 무기 +0.2% |
| 내구 | 피해 받기(받은 피해만큼, 최대 6), 가드로 막기 2 | 바위 들기 세트 (조약돌 8 + 실) | 최대 체력 +0.15/점 |
| 민첩 | 달리기 8칸 1, 대시 2, 회피기 4 | 모래주머니 (모래 5 + 가죽 4) | 이동 속도 +0.05%/점, 스태미나 회복 +0.5%/점 |
| 지능 | 책 우클릭(독서, 10초마다 3) | 백과사전 (책 3 + 먹물) | 스태미나 +0.5/점, 직업 기술 +0.1%/점 |
| 가벼운·중간·무거운 무기 숙련 | 검·창·대검으로 타격 3 | 검술·창술·대검술 교본 (책 + 철 2 + 깃털 / 책 + 철 + 막대 2 / 책 + 철 3) | 그 무기 피해 +0.4%/점 |
| 직업 숙련 | 직업 기술 사용 4 | 직업 수련서 (책 + 청금석 2 + 종이) | 직업 기술 피해 +0.4%/점 |

- **수련 도구**: 소모품이 아니라 **내구도가 있는 도구** — 하나로 20번 확정 (확정 1번 = 내구도 1, 다 닳으면 부서짐). 전용 도트 텍스처 8종 (뒤틀린 균 낚싯대 바탕 + custom_model_data 7101~7108, `tools/make_tool_textures.py`). 예전 소모형 도구도 그대로 1개씩 쓸 수 있음
- **재능 카드**: 파워업마다 Deepwoken 처럼 **카드 선택창이 바로 뜸** (파워 상승 문양 → 뒷면이 깔리고 한 장씩 뒤집힘). 조건을 만족하는 카드 3장(인간 4장) 중 왼쪽 클릭으로 1장 고르기, 오른쪽 클릭(또는 소각 모드)으로 **소각** = 앞으로 다시 안 나옴 (소각 토큰: 처음 1, 파워업마다 +1, 최대 3, 마지막 한 장은 못 태움). ESC 로 미루면 성장 창에서 다시 (일반 70·희귀 25·전설 5). 지금 들어간 14장: 사냥꾼의 허기, 연계의 리듬, 무거운 마무리, 날카로운 스위치, 도발자, 숨 고르기, 두꺼운 피부, 남은 힘, 오뚝이, 그림자 발놀림, 한 번 더, 나무꾼, 독학, 내가 우위다
- **특성**: 짝수 파워마다 1점 (최대 24, 한 곳 6) — 생명력(최대 체력 +5%) · 지식(스태미나 +10) · 숙달(평타·무기 +3%) · 공명(직업 기술 +3%)
- **스킬 숙련**: 직업 기술은 쓸 때마다 +2%, 100% 면 ★숙달 (재사용·비용 −20%)
- **종족**: 처음 접속하면 랜덤 (인간 47 · 수인 13 · 혼혈 10 · 마술 가계의 피 8 · 호문쿨루스 8 · 성흔자 6 · 파문 계승자 5 · 마안 보유자 3), 한 번 무료로 다시 돌림. 지금 효과: 인간(카드 +1·스탯 경험치 +10%), 수인(밤 야간 투시·지능 −20%), 혼혈(체력 30% 이하 반전: 피해 +25%·가드 불가), 호문쿨루스 마술형(최대 체력 −15%). 나머지는 해당 직업·시스템이 들어올 때
- **성장 창 (K)**: 마인크래프트 보관함 창 모양 (회색 상자, 왼쪽 레시피 책 탭, 바닐라 단추·발전과제 테두리·경험치 막대·보스 막대 그림을 그대로 씀). 상태 탭 = 파워(도전과제 테두리 + 경험치 레벨 같은 초록 숫자)·이름/종족/직업·존재치(경험치 막대)·소각 토큰 슬롯·특성 4개(목표 테두리, + 단추)·스탯 8개(과제 테두리 안에 그 스탯의 수련 도구, 아래 수치 + 다음 1점 경험치 막대, 확정 대기면 노란 테두리 + 초록 +N → 클릭하면 도구로 확정), 재능 카드 탭 = 목록 + 카드, 기술 숙련 탭 = 보스 막대. 모드가 없는 접속자는 예전 상자 메뉴
- **재능 카드 모양**: 어두운 심층암 몸통 + 등급 테두리(일반 철 · 희귀 다이아몬드 · 전설 금 반짝임) + 이름 띠 + 효과 도트 그림 + 분류(전투 빨강 · 생존 초록 · 생활 금색) · 등급 + 효과 + 조건 띠. 그림 14장은 Deepwoken 카드처럼 흰 종이에 먹선으로 그린 상징 하나를 도트로 (직접 그린 상징: 사냥꾼의 허기 = 할퀸 자국, 연계의 리듬 = 음표, 무거운 마무리 = 주먹, 숨 고르기 = 소용돌이, 두꺼운 피부 = 등딱지, 남은 힘 = 모래시계, 오뚝이, 그림자 발놀림 = 흐려지는 발자국, 한 번 더 = 꿰맨 하트, 나무꾼 = 그루터기의 도끼, 독학 = 펼친 책, 내가 우위다 = 왕관 …) — `tools/make_card_art.py`. 파워 상승은 발전과제 알림처럼 위에서 내려옴(도전과제 소리), 뒤집힐 때 책장 소리
- **색감**: 바닐라 창 모양 그대로 어두운 심층암 색 + 금색 제목줄·구분선
- 관리자: `/bbc admin ep <플레이어> <양>`, `/bbc admin stat <플레이어> <스탯> <점>`, `/bbc admin tool <스탯> [개수]`

## 연금술사 (4단계 이식) — `job/alchemy`
무현버스 duel 모드의 연금술사를 옮기고 포켓몬에 기대던 부분을 바꿈.
- **등가교환**: 연성진 블록 우클릭 → 분해(아이템 → 연성 에너지, 처음 분해한 아이템은 '이해')·연성(에너지 → 이해한 아이템, 손실 견습 22% → 대연금술사 15% → 진리 5%). 가치표 `config/bbc_alchemy.json` (레시피 원가 자동 계산). 하루 분해 한도. `/alchemy`(내 정보) `/alchemy value` `/alchemy search <단어>` `/alchemy open`(진리를 본 자: 연성진 없이)
- **입문**: 연성진 화면의 '연금술사 되기' — 이해한 아이템 50종 · 누적 분해 50,000 E · 공물(다이아몬드 블록 1 · 금 블록 4 · 레드스톤 블록 8 · 자수정 조각 16). 연성 장갑 지급
- **등급** (연성에 쓴 에너지 누적): 견습 → 연금술사 10만 → 숙련 40만 → 대연금술사 100만 → 진리를 본 자. (관리자) `/alchemy xp <플레이어> <숙련도>`, `/alchemy give <플레이어> <E>`
- **진리의 문** (대연금술사, 연성진 화면 아래 줄의 '진리의 문 열기' 버튼 — 대가 연성 에너지 1,048,576 E + 경험치 30레벨 + 몸 일부): 하얀 차원 `bbc:truth` 연출, 통행료 팔(공격 −30%)·다리(이동 −15%)·심장(최대 체력 −6) 중 하나 → 손뼉 연성(연성진 없이)·손실 5%. 오토메일(의수·의족·강철 심장)로 대신하면 오히려 강해짐, 모델에 잃은 팔·다리와 오토메일이 보임
- **현자의 돌 연성** (대연금술사): 에너지 + 재료 + **영혼 300개**(대연금술사가 된 뒤 쓰러뜨린 생명: 몹 1 · 주민 5 · 플레이어 25, 포켓몬 제물 대신) · 개인 30일 · 서버 3일에 1개
- **현자의 돌 사용** (하나 고르면 1개 소모): ① 리스크 없는 결투(돌 들고 플레이어 우클릭, 3분, 체력이 다하면 쓰러지는 대신 끝, 이기면 상대가 든 아이템을 빼앗음) ② 존재의 비약(다음 파워 문턱의 50%) ③ 운명의 계시(희귀 이상 재능 카드 3장 중 1장) ④ 등가교환의 끝(`/wish <아이템>`, 무기·갑옷·우리 모드 아이템 제외) ⑤ 연성 골렘(연금술사 전용 동료, 따라다니며 같이 싸움, 죽으면 5분 뒤 다시) ⑥ 생체 연성(임플란트가 생기면). 지니고 있으면 연성 손실 감소
- **아이템**: 연성진 `bbc:alchemy_circle` (레드스톤 4 · 자수정 조각 4 · 다이아몬드 1, 블록으로 설치해 우클릭) · 연성 장갑 `bbc:alchemy_glove` (흰 양털 3 · 연성진 1 · 가죽 1, 입문하면 하나 지급)
- **평타·대기 (다른 게임의 에드워드 평타 영상을 프레임 단위로 다시 봄)**: 대기 = 옆으로 서서 왼팔을 상대 쪽으로 뻗고 손바닥을 폄, 오른 주먹(오토메일)은 가슴 앞, 다리를 앞뒤로 벌림 (걸을 땐 팔만 잡고 다리는 바닐라 걷기). 평타 5타 = 오토메일 칼날 사선 베기(오른팔을 머리 위로 들었다 왼무릎 앞까지) → 왼손 올려 훅 → 오른 스트레이트 → 돌며 올려차기 → 손뼉·웅크려 땅 짚고 쳐올리기(연성진 + 바위 기둥). 띄우기 = 땅 짚고 올려치기(가시). 팔이 상대를 가리키도록 몸 회전만큼 팔 각도를 맞춤 (예전엔 40° 넘게 빗나가 어색했음). 모션 `al_*`, `stance_al(_walk)`
- **기술 (ABA 에드워드 카드, 기준 스탯 지능, 진리 전에는 연성 장갑을 손에)**: ① 기둥(손뼉 → 바위 기둥이 땅을 타고 쫓아가 들이받음) ② 무기 연성 — 땅: 창을 뽑아 20초 창 평타 ×1.5, 다시 누르면 돌진 찌르기 / 공중: 오토메일 의수(없으면 장갑 낀 팔)에 칼날을 연성해 20초 칼날 평타(`ab_*`), 다시 누르면 발밑 기둥을 밟고 솟구쳤다가 칼날을 꽂으며 낙하 → 착지 충격(다운·가드 깨기). 알림 메시지 없음 ③ 가시(앞 땅에서 가시 무더기, 띄움·가드 깨기) ④ 기둥 벽(ABA Spike 모션: 뒤로 백덤블링 → 착지하며 땅을 짚으면 앞으로 기둥들이 부채꼴로 줄지어 솟아 띄움, 가드 깨기) + 고를 거리: ⑤ 대지 붕괴(광역, 가드 깨기) ⑥ 돌 산탄(돌 파편 7개 부채꼴, 견제) ⑦ 바위 족쇄(조준한 상대를 1.5초 묶음) ⑧ 연성 방벽(순간 벽, 0.6초 안에 맞으면 패링하고 기둥으로 되받아침)
- **각성 '손뼉 연성'** — **컷신 170틱(≈8.5초, 각성 음성 길이)** (참고: 다른 게임의 에드워드 연출): 먼지 낀 발 → 얼굴까지 천천히 훑어 올라감 → 얼굴 앞 합장 손뼉 → 두 팔을 들어 땅을 내리침, 바로 위에서 본 거대한 연성진 → 멀리서 사방으로 가시 숲이 솟고 먼지 속에서 코트가 찢겨 날아감 → 가시 숲 속에서 일어나 한 발 내딛으며 오토메일 손바닥을 앞으로. 컷신 동안 무적·시선 고정, 각성 시간은 그만큼 늘어남. 각성 중엔 테마곡(주변 24칸도). 이후 기술 칸이 바뀜 (HUD 이름도): ① 창조의 기둥(ABA처럼 빠르게 반 바퀴 돌며 뒤로 약 5칸 이동, 거꾸로 뜬 채 1차 기둥 셋 → 나머지 반 바퀴 돌아 착지하며 2차 기둥 셋(가운데 큰 기둥이 날림·가드 깨기) + 앞을 막는 기둥들) ② 신의 손(땅: 양옆 바위 손 박수 → 짓눌러 다운 / 공중: 상대 아래 땅을 뚫고 관절까지 있는 거대한 바위 주먹이 솟구쳐 올려침 — 둘 다 가드 깨기) ③ 가시밭(연타 5번 → 가시 숲, 가드 깨기, 짧은 컷신) ④ 최후의 일격(가드 깨기·멀리 날림). ⑤~⑧ 은 그대로
- **가드 깨기 배분**: 거리 시작기(기둥)·견제(산탄)·묶기(족쇄)·평타 연장(창·칼날 평타)은 안 깸. 선딜이 길거나 몸을 던지는 기술만 깸 — 가시 · 기둥 벽(백덤블링 선딜) · 칼날 낙하(솟구쳤다 떨어지는 동안 보임) · 대지 붕괴, 각성판 4종(창조의 기둥은 마지막 기둥만)
- **다운 슬램** (`al_slam`): 공중에서 손뼉 → 그 순간 손(오토메일·장갑)에 칼을 연성 → 몸 전체를 뒤로 젖혀 칼을 들었다가 앞으로 70° 고꾸라지며 내리찍음 → 칼은 사라짐
- **모션 원칙 (ABA 기둥·가시·창조의 기둥 프레임)**: 다리를 오므리지 않고 옆으로 넓게 벌려 낮게 버팀 — 깊은 런지·한쪽 무릎 꿇기·넓은 기마 자세, 몸 전체를 내림(`bodyPos`). 손뼉은 두 손바닥이 가슴 가운데서 만나고 팔꿈치는 바깥 (IK 로 손끝 위치를 맞춤). 백덤블링은 웅크림 3틱 → 12틱에 걸쳐 한 바퀴 → 16틱 착지
- **사운드** (`AlchemySounds`): 손뼉 연성마다 연성음, 무기 연성 `weapon_ed`, 창조의 기둥 `atk_ed`, 각성 `awaken_ed`, 각성기 `ground_ed`, 최후의 일격 `rush_ed`, 각성 테마곡. 컷신 대사는 컷신을 보는 사람에게 화면 기준으로(카메라가 멀어도 안 작아짐), 테마곡은 '음반' 소리 설정으로 (음악 볼륨을 꺼 둔 사람도 들림). 소리 이벤트만 모드에 있고 소리 파일은 따로 주는 리소스팩 `BBC_Alchemist_Sounds.zip`(v2: 음성 +8dB, 연성음 0.6) 에 — 모드를 업데이트해도 다시 넣을 필요 없음, 소리가 추가될 때만 새로
- **오토메일별 차이**: 의수(또는 없음) = 공중 무기 연성으로 팔 칼날·칼날 평타, 마무리 칼날 낙하, 다운 슬램 손에 칼 / 의족 = 평타가 발차기 위주(`alk_*`: 왼발 앞차기 → 오른발 돌려차기 → 왼발 옆차기 → 뒤돌려차기 → 왼발 뒤꿈치 내리찍기), 공중 무기 연성은 왼다리 정강이에 칼날(발차기 평타가 더 세고 길게), 마무리는 칼날 단 왼발 드롭킥, 다운 슬램은 다리 칼날 발뒤꿈치 찍기 / 강철 심장 = 공중 무기 연성이 심장 펌핑(20초 과부하: 평타 후딜↓ ×1.2, 1초마다 심장이 뜀), 마무리는 심장 폭주(두 번 펌핑 → 붉은 충격파, 날림·가드 깨기), 다운 슬램은 심장 펌핑 충격파
- **블록 디스플레이 밝기 고정**: 땅속에서 솟는 바위 손·기둥이 새까맣게 보이던 문제

## 연출
- **컷신** (`client/Cutscene`): 서버가 `CutscenePayload`(대본 이름·시전자·대상)를 보내면 카메라가 대본대로 움직임 (시전자 기준 위치, 키 사이 부드럽게 · 컷 · 끝에서 원래 카메라로 섞여 돌아옴), 위아래 검은 띠 + 기술 이름(금색). 그동안 내 몸이 보이고 움직임 입력은 막힘. 대본: `al_awaken` · `al_ult` · `al_forest`

  일본 만화식 연출: 효과음 그림 글자(ドン! ザンッ! ズドォン!! ガギィン!! ゴゴゴゴ, Dela Gothic One·OFL 로 단어마다 그린 그림 글꼴, tools/make_sfx_font.py), 맞은 자리 흰·검은 가시 파열 + 번쩍 원 + 만화 타격 별(평타도 작게), 퍼지는 흰 충격 고리(ABA), 큰 타격 뒤 낮게 깔리는 흙먼지 구름, 베기 마무리의 먹 초승달, 휠윈드·회전 후리기의 흰 소용돌이, 날아가는 상대 뒤 속도선, 화면 집중선, 바닥 돌덩이·흙먼지, 먹선 테두리 칼자국, 화면 흔들림, 화면 번쩍임(각성·각성기), 히트스톱(넉백·다운·각성기 마무리 때 둘 다 몇 틱 멈춤)
