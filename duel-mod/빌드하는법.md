# 결투 장갑 모드 (duel) 빌드하는 법 — Windows

## 0. 준비 (한 번만)
1. JDK 21 설치 (Adoptium Temurin 21 권장)
   - 명령 프롬프트에서  java -version  → "21" 이 보이면 OK
2. 인터넷 연결 (첫 빌드 때 의존성을 내려받음, 5~10분)

## 1. 폴더 준비
- Duel_Mod_Source.zip 을  C:\duel  에 압축 해제
- C:\duel 안에 build.gradle 이 바로 보여야 함 (폴더가 한 겹 더 있으면 안 됨)

## 2. gradlew 만들기 (한 번만)
그라니테 폴더(C:\granite)에서 아래 3개를 C:\duel 로 복사하면 끝:
    gradlew.bat
    gradlew
    gradle\  (폴더째)
그라니테 폴더가 없으면, Gradle 을 설치한 뒤 C:\duel 에서:
    gradle wrapper --gradle-version 8.10

## 3. 빌드
C:\duel 폴더 주소창에  cmd  입력 후 엔터 → 열린 창에서:
    .\gradlew.bat build --console=plain
"BUILD SUCCESSFUL" 나오면 성공

## 4. 설치
- 결과물:  C:\duel\build\libs\duel-1.0.0.jar
  (duel-1.0.0-sources.jar 가 같이 생기면 그건 무시)
- 서버 mods 폴더 + 내 클라이언트 mods 폴더 양쪽에 넣기
- 다른 플레이어도 클라이언트에 넣어야 접속 가능

## 수정 후 다시 빌드
.java 파일 고친 뒤 3번만 다시 실행. 에러 나면 로그 전체를 보내주세요.

## 결투 장갑
- 들고 플레이어 우클릭 → 수락 없이 1:1 배틀
- 이긴 쪽이 진 쪽 인벤토리(메인 36칸 + 왼손, 갑옷 제외)에서 랜덤 한 칸을 가져감
- 도망(항복)도 패배. 일반 /challenge 배틀에는 적용 안 됨
- 시작 시 1개 소모, 10초 쿨다운
- 조합(레드스톤 / 가죽 금괴 가죽 / 가죽) 또는  /give @p duel:duel_glove

## 현자의 돌
- 입수: 관동 챔피언 그린 첫 승리 시 1개 (RCT 보상표에 자동 추가)
  수동 지급:  /give @p duel:philosophers_stone
- 허공 우클릭 → 효과 선택창. 하나 고르면 돌 1개 소모
  ① 리스크 없는 결투 : 돌을 들고 플레이어 우클릭. 져도 잃는 것 없음,
                       이기면 [아이템 강탈 / 포켓몬 강탈(랜덤 1마리)] 선택
  ② 이상한사탕 100개
  ③ 마스터볼 3개
  ④ 원하는 아이템 1개 :  /wish <아이템>  (탭 자동완성, 취소는 /wish)
  ⑤ 연금술사 피카츄   : 준비 중 (돌 소모 안 됨)
  ⑥ 랜덤 이로치       : 전설·환상·커스텀 포함 전체에서 Lv.50
- ①은 결투가 시작될 때, ④는 아이템을 받을 때 돌이 소모됨

## 연금술 (등가교환 연성진)
- 블록: 등가교환 연성진 (duel:alchemy_circle)
  - 조합: 레드스톤 4 + 자수정 조각 4 + 다이아몬드 1 (가운데)
- 설치 후 우클릭 → 연성 화면
  - 내 인벤토리 Shift+클릭 = 그 묶음 분해 → 에너지(E)
  - '분해 상자' = 여러 개 넣고 닫으면 한꺼번에 분해
  - 분해해 본 아이템만 목록에 생김 → 클릭해서 연성 (좌 1개 / 우 16개 / Shift 1묶음)
- 연성 비용 = 가치 × 1.25 (현자의 돌을 지니고 있으면 × 1.10)
- 하루 분해 한도 65,536 E (다이아 8개 분량)
- 가치표·손실률·한도·금지 목록: 서버 config/duel_alchemy.json (처음 실행 시 자동 생성)
  - 수정 후 /alchemy reload
- 명령어: /alchemy, /alchemy value (손에 든 것 가치), /alchemy search <단어>
  - 관리자: /alchemy reload, /alchemy give <플레이어> <양>
- 현자의 돌 연성: 연성 화면 아래줄 '현자의 돌 연성' 버튼
  - 대연금술사 이상 · 에너지 4,194,304 E · 재료(네더의 별 3, 바다의 심장 1, 메아리 조각 8)
  - 파티 6마리 전부 Lv.100 → 전부 소멸 · 개인 30일 · 서버 전체 3일에 1개
  - 설정: stoneCost / stoneItems / stoneSacrifices / stoneMinLevel / stoneCooldownDays / stoneServerCooldownDays
- 계열: 같은 계열 아이템 하나만 분해하면 계열 전체 연성 가능 (설정 families)

## 직업 — 연금술사 (/job)
- 입문 조건: 연성진으로 이해한 아이템 50종 + 누적 분해 50,000 E
  + 공물(소모) 다이아몬드 블록 1 · 금 블록 4 · 레드스톤 블록 8 · 자수정 조각 16
- 등급 (숙련도 = 연성에 쓴 에너지)
  1 견습 연금술사 0 — 손실 22%
  2 연금술사 100,000 — 손실 20%, 분해 한도 ×1.25
  3 숙련 연금술사 400,000 — 손실 17%, ×1.5, 현자의 돌 연성 가능 (무직·1~2등급은 불가)
  4 대연금술사 1,000,000 — 손실 15%, ×2, 진리의 문 도전
  5 진리를 본 자 — 손실 5%, ×3
- 진리의 문: 연성진 근처에서 /job → 진리의 문
  - 대가: 에너지 1,048,576 E + 경험치 30레벨 + 몸 일부 하나(영구)
    팔: 공격력 -30%·채굴 -20% / 다리: 이동 -15% / 심장: 최대 체력 -6
  - 새하얀 공간(duel:truth 차원)으로 끌려가 거대한 문이 열리는 연출 후 복귀
- 진리 혜택: 연성진 없이 연성(G 키 · /alchemy open),
  이해 없이 모든 아이템 연성, 손실 5%, 분해 한도 ×3, 현자의 돌 제물 4마리·3일

## 전투 모드 (조작 설정 → '무현버스 연금술'에서 키 변경)
- ` (물결표): 전투 모드 켜기/끄기 — 연금술사만. 진리 전에는 연성 장갑을 손(주/보조)에 들어야 함
  연성 장갑 조합: 흰 양털 3 + 등가교환 연성진 1 + 가죽 1 (가운데 연성진, 아래 가죽). 켜면 현자 피카츄 테마곡 재생
- 전투 모드 중 1~7: 연성 기술 (핫바 등 같은 키의 다른 단축키보다 우선, 끄면 원래대로)
- G: 손뼉 연성 (진리를 본 자, 전투 모드 밖에서)
- 자동 해제: 다시 누름 / 사망 / 포켓몬 배틀 시작 / 접속 종료
- 등급 2부터 파티의 연금술사·현자 피카츄가 나와서 같이 싸움 (주인 공격 판정, PvP 설정 따름)
  연금술사 폼: 강철 팔칼날 9 · 그라운드 포지 8 · 번개 펀치 8 · 웨폰 포지(주인 힘 I)
  현자 폼: 어스 리빌드 9 · 스톤 포지 11(반경 2.5) · 라이프 포지(주인 +8) · 소울 배리어(주인 저항 II)
- 스태미나: 기술은 연성 에너지 대신 스태미나 사용 (전투 모드 중 화면 위 노란 바)
  최대 = 150 + 등급×30 + 레벨×2 (레벨 100까지) · 초당 회복 = 5 + 등급×1.2 + 레벨×0.08 (전투 모드 밖 2배)
- 포켓몬에게는 피해 ×2.5 (엔티티 체력이 많아서)
- 대상: 몹 · 야생 포켓몬 · 플레이어(PvP 설정) · 남의 포켓몬(PvP 켜졌을 때). 내 포켓몬·배틀 중 포켓몬 제외
- 기술 (키 · 해금 · 스태미나 / 재사용)
  1 대지 가시 · 견습 · 20 / 6초 — 앞으로 8칸 가시, 10 피해 + 띄움
  2 대지 방벽 · 연금술사 · 25 / 12초 — 5×3 벽, 8초 뒤 사라짐
  3 무기 연성 · 숙련 · 35 / 25초 — 땅에서 강철 창을 뽑아 손에 듦 (공격력 12 · 사거리 +1.5 · 5번 때리면 부서짐 · 60초 뒤 자동 소멸)
    원래 손에 든 아이템은 왼손으로, 왼손이 차 있으면 인벤토리로
  4 바위 기둥 · 대연금술사 · 40 / 20초 — 상대(24칸) 추적 투사체, 16 피해 + 넉백, 궤적에 기둥이 남음
  5 신의 손 · 대연금술사 · 55 / 30초 — 조준한 상대(30칸) 추적, 바위 손 13 피해 + 4초 구속(이동·점프·순간이동 불가)
  공중의 상대를 잡으면 손목+팔뚝이 땅에서 뻗어 올라옴
  6 대지 붕괴 · 진리 · 80 / 60초 — 주위 7칸 가시 물결 22 피해 + 둔화
  7 최후의 일격 · 진리 · 100 / 90초 — 10초 공격력 +14, 때린 상대 갑옷 전부 파괴

## 테스트용 관리자 명령어 (OP 권한 2)
- /job admin info <플레이어> — 직업·등급·숙련도·에너지·통행료·대기시간 보기
- /job admin rank <플레이어> <0~5> — 등급 바로 설정 (0 무직 · 5 진리를 본 자)
- /job admin xp <플레이어> <양> — 숙련도 추가 (음수면 감소)
- /job admin toll <플레이어> arm|leg|heart|none — 통행료 변경 (none = 원래 몸)
- /job admin gate <플레이어> [arm|leg|heart] — 진리의 문 연출만 보기 (대가·공지 없음)
- /job admin cooldown <플레이어> — 현자의 돌·연성 기술 대기시간 초기화
- /job admin known <플레이어> — 연성 가능한 모든 아이템을 '이해'
- /job admin reset <플레이어> — 직업·진리·통행료·숙련도 초기화 (에너지·이해 목록 유지)
- /alchemy give <플레이어> <양> — 연성 에너지 지급 (음수면 회수)
- /alchemy reload — 가치표·설정 다시 읽기

## 오토메일 (진리를 본 자의 통행료 보완 — 우클릭으로 영구 장착)
- 오토메일 의수 (팔): 철 블록 6 + 구리 블록 1 + 레드스톤 블록 1 + 네더라이트 주괴 1
  → 팔 페널티 제거 + 공격력 +15%, 채굴 +15%, 넉백 저항 +20%
- 오토메일 의족 (다리): 철 블록 6 + 레드스톤 블록 1 + 피스톤 1
  → 다리 페널티 제거 + 이동 +10%, 턱 오르기 +0.5칸, 안전 낙하 +4칸
- 강철 심장 (심장): 철 블록 4 + 금 블록 4 + 레드스톤 블록 1 + 다이아 블록 1
  → 체력 페널티 제거 + 최대 체력 +4, 방어 +3
- 바친 부위와 같은 오토메일만 장착 가능
